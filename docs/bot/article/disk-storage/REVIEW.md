# 独立レビューと手元検収

実装担当と別の担当が、指示commitから成果物headまでの全差分を読む。review対象SHA、finding、修正後の再検査を記録する。手元AIはさらに全行と完成PNGを確認する。

- 3.26→25.97→27.15 GiB、22.71+約1.18=約23.89の段階を混ぜない。論理ファイルサイズと実際の空き増加を区別。
- 動画17本の確認後に元を整理した順序、ローカルデータ保持、ソースの変更保持を正しく説明。
- 外部直接buildは今回の経路の失敗。原因未確定を断定せず、Dで生成した結果と区別。
- 合成CLI試験と実プロジェクトの本番利用、ソース状態確認と全アプリ起動確認を混同しない。
- 手動の配置ルール・清掃道具・見直し日を自動チェック/自動削除/共通ルール実装済みと書かない。
- 実パス、私有repo名、実ホスト、IP、人物、watchlist、認証、生ログの持ち出しなし。コード例は相対パス。
- 文体が敬体、架空の体験なし、禁止ダッシュなし。前記事URLを公開前のものとして扱わない。未読の内容は創作しない。
- 4画像の役割・文字・数値・寸法・生成元・差込み位置・直後の説明一致。hero猫なし、右下予約領域あり。
- 本文から参照する全PNGの存在を機械確認し、HTMLのoverflowと日本語切れを描画で確認。
- 直下は完成PNGと記事/進捗MD・publication.jsonのみ。中間物はsrc/。他案件・製品source変更なし。
- published:false、Draft PR。投稿・merge・課金・環境の恒久変更なし。

不能な検査は理由と次に必要な条件を記録し、PASSに数えない。PNGがあることを画像生成・品質検収の代わりにしない。
