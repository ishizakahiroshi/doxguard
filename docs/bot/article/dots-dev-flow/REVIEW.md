# 独立検収
- FACTSと本文の主張が一致する。主題が開発の仕方になっている(作った機能の仕様説明や、dotsの環境のつまずき話が主題になっていない)。
- 前作への言及とリンクが冒頭近くと締め近くにあり、その媒体の前作URLを使っている。
- 外部の仕様・条件・数値に出典URLが近接している。FACTSに無い数字が無い。
- 非公開repo名、社名、人名、実ホスト、Slackのワークスペース名・ID・会話URL、PR番号、commit SHA、ホームの絶対パス、監視語が無い。
- 製品の優劣の比較になっていない。「別の製品なので見落としが重なりにくい」の範囲に留まっている。
- 3版にdots執筆注釈と手元担当の開示がある。
- Zenn・Qiita・noteの各読者に合わせた文章になっている。frontmatterが各媒体で有効(Qiitaは id:'' / organization_url_name:null / ignorePublish:false)。noteはH1タイトル・##/###見出し・5行の画像目印。
- 本文とhero/要約/挿絵/fig2枚が揃い、全画像が本文に挿入されている。Zenn用画像は1枚3MB以下。
- heroが生成シーンと固定素材と日本語の後合成である。
- 日本語、数値、因果、余白、リンク、画像URLを実物で検査する。
- 原稿のlintと画像の目視を手元でも独立実施する。
- 公開は手元の一担当。3媒体で安定keyと状態とreceiptを保存する。
- 公開済みの場合は同じ記事IDを更新する。結果不明の再投稿は禁止。
- 3媒体のURLで正しい投稿者、公開状態、本文と5画像の実表示を手元が確認する。
