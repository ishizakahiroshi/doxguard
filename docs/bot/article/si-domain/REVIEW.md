# 独立レビューと手元検収

実装担当と別の担当が、指示commitから成果物headまでの全差分を読む。review対象SHA、finding、修正後の再検査を記録する。手元AIはさらに全行と完成PNGを確認する。

- 本文で使った数値・引用・日付のすべてに、同じ段落か直後の行のURLがある。SOURCES.mdの一覧と本文の出典が一致し、一次情報と報道を区別している。
- .aiの年別収入と予算比、.siの登録数は、一次情報で確認した値か、出所を明示した報道の値。媒体間でずれる数字を混ぜていない。図・infographic・本文の数値が一致。
- 大統領令の内容（対象が行政部門の文書であること、定義を誰が作るか）を原典どおりに書き、民間への強制などに誇張していない。
- .aiの収入が減ったと断定していない。spacexsi.comの所有者を転売目的と断定していない。アンギラを独立国と書いていない。
- 本人の意見4点（箱物行政の匂い、AIでええやん、転売ヤーみたいな動きの懸念、悲しい事態）が、事実と区別された感想として入っている。政治的な揶揄・人物評価に寄っていない。
- X投稿の引用は、公人・公式・報道機関以外の個人名を出していない。引用した投稿にURLがある。
- note形式: H1タイトル、`## `/`### `見出し、箇条書きは`・`、画像は5行の目印ブロック、URLの直後に説明やカッコがない。フッター全文、開示文の画像種別との一致、最終行が13個のハッシュタグ1行。
- 文体が敬体、架空の体験なし、禁止ダッシュなし、AIっぽい総括・三段構成なし。
- 関連記事は公開済みURLだけ。未読の内容を創作していない。
- 4画像の役割・文字・数値・寸法・生成元・差込み位置・直後の説明が一致。hero猫なし、右下予約領域あり。実在ロゴ・実在人物の顔の混入なし。
- 本文から参照する全PNGの存在を機械確認し、HTMLのoverflowと日本語切れを描画で確認。
- x-post.mdが重み付き280以内、末尾URL、ハッシュタグなし。
- 直下は完成PNGと記事/進捗MD・SOURCES.md・publication.jsonのみ。中間物はsrc/。他案件・製品source変更なし。
- 私有パス、私有repo名、認証、生ログの持ち出しなし。
- Draft PR。投稿・merge・課金・ドメイン取得・環境の恒久変更なし。

不能な検査は理由と次に必要な条件を記録し、PASSに数えない。PNGがあることを画像生成・品質検収の代わりにしない。
