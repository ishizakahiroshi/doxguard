文体
・敬体、一人称の回避、短い段落、会話的な H2、「〜することが大切です」型の総括定型なし、三段構成の機械的な反復なし。禁止ダッシュ（`—` `―` `——`）が本文・見出し・画像のどこにもない。
・太字が 3 か所以内。絵文字なし。note の見出し（`## `/`### `）、`・` の箇条書き。H1 が本文に残っていない。
・依頼者の言い回しと感想が意味を変えず残り、新しい体験談や感想が足されていない。
・他の記事・公式資料に言及した全段落の直後に URL がある。関連記事の URL は初出 1 回、記事 3 本が公開済みのもの。
