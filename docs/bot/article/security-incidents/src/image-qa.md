## 2. HTML文字合成

render_images.py の各ラベルはHTMLに変換し、MuPDF HTML Storyで組版しています。8枚それぞれの編集可能なHTMLを保存しました。日本語文字を生成画像に任せず、heroの見出し、infographicの説明、3枚のfigのラベルを後から合成しています。3枚の本文挿絵は文字を足していません。

本文担当との照合により、05_fig-separationは技術的な使い分け、06_illustration-storageは倉庫の比喩、07_fig-protectionは各社の分離と非保持、という掲載順に確定しました。

数値はFACTS.mdにある値だけです。公表単位はアカウント数、人、個人情報の件、登録ユーザー数で区別し、合計人数を作っていません。一次情報確認担当が数値4社と分離6社の本文を照合済みと報告した後に、図の出典注記を確定しました。日付訂正に影響される発表日ラベルは図に使用していません。詳しいURLと確認範囲はSOURCES.mdを参照してください。

## 3. PNG描画と機械検査

MuPDF HTML Storyの組版結果とネイティブな図形を1600×900のPNGへ描画しています。生成素材は画面に合わせて配置するだけで、内容の描き直しはしていません。Chromiumでの描画結果とは表記していません。

最初の実行では05_fig-separationの補足2か所が指定ボックスに入らないため、検査が停止しました。ボックスの高さと行間を調整し、文字の自動縮小をせずに再描画しています。最終版では全ラベルのscale=1、spare_height>=0、全描画文字の座標が画面内であることを検査しました。禁止ダッシュ2種類はテキスト関数で拒否しています。

全8枚の実寸は1600×900。再描画前後で8枚すべてのSHA-256が一致しました。全ハッシュ、素材ハッシュ、プロンプトハッシュ、役割、出典はimage-manifest.json、文字ボックスと描画検査はimage-render-checks.jsonにあります。
