# 制作担当の検査記録

## 制作方式

- 図版制作担当: dots制作担当。本文担当とは別作業で制作。
- AI生成: 利用可能な画像生成機能で、文字のないhero背景、infographic用の絵、許可リストの比喩となる本文挿絵を生成。全て同一の採用元。
- 編集元: hero.html、infographic.html、fig.svg、fig.html、各プロンプト、3枚のAI生成元画像。
- PNG化: render.py。HTMLの日本語テキストを読んで描画する固定レイアウト用Pillowアダプター。汎用HTMLエンジンではないため、レイアウト変更時はHTMLとアダプター双方を調整する。概念図はInkscapeでSVGから出力する。
- 本文挿絵の加工は1600×900への寸法調整のみ。heroとinfographicはBRIEF指定の後段文字合成。
- HTMLブラウザ書き出しの試行は起動制約、ローカル表示の試行はURL方針により利用できなかった。能力全体の不能とは扱わず、完成物の実物を別途開いて目視した。

## 完成PNGの実物目視

制作担当がhero.png、infographic.png、illustration.png、fig.pngを画像表示機能で開いて確認した。

- hero: タイトルが本文と一致。日本語の欠けなし。猫なし。右下の指定矩形は均一背景で、文字・イラスト・影を置いていない。
- infographic: AIの絵と日本語の4区分を確認。保留保存と台帳登録完了の区別、実操作の通し確認は未実施という限定を明示。最初の出力で小見出し参照の不具合があり、修正後の実物で再確認。
- illustration: 許可した項目をふるいにかける比喩。生の文章や実画面はなく、本文の許可リスト節と一致。
- fig: 業務経路と記録経路を分離。保留保存は未確定、別回収・専用トランザクションで台帳へ反映し、確定後に保留を除去。記録不能の境界も表示。実構成や台数を示していない。
- 全体: 寒色パレット、日本語の切れ、余分な文字、猫の混入、ブランド・ロゴ、案件識別情報、到達の無条件保証がないことを確認。

## 形式確認

- 完成PNGは4枚、全て1600×900。本文に各1回の相対参照。
- heroの空き領域は右下340×250px。画素上でも単色であることを検査する。
- frontmatter、約4000字、画像の直後の説明、AI開示文、告知下書きは本文検査記録を参照。
- 題材の実環境、実画面、実台帳の操作検証をこの制作で追加実施したとは主張しない。
- 追加課金、認証情報のコピー、媒体投稿、サイト公開、X送信、merge、別repo変更なし。
- これは制作担当の自己確認。独立レビューと手元の最終検収は別途必要。
