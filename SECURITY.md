# Security reporting

Do not put vulnerability details, reproduction steps, watchlists, credentials,
personal data, or private file paths in public issues or pull requests.

Report vulnerabilities privately through GitHub private vulnerability
reporting: open the repository's "Security" tab and choose "Report a
vulnerability" (https://github.com/ishizakahiroshi/doxguard/security/advisories/new).
This was enabled and checked on 2026-11-15. No other private submission address
is advertised, so do not assume that an unlisted address or a public issue is a
confidential channel.

Supported versions: the latest released version. No response deadline or bounty
is promised here.

Public fixes and release notes are published through this repository's releases
and npm package. Please wait for coordinated remediation before public disclosure.
